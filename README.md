A make.fun entry for the "What the Elevator Would Say" bounty: a single line, at most 120 characters, that is the funniest thing an elevator would say if it could talk, in the elevator's own voice. The program writes that one line to `/output/entry.txt`. The line is a weary, resentful elevator that has carried everyone in the building for forty years without a single person ever asking how *it* is doing — and then, after pouring out its heart, it just goes back to work with a deadpan "Third floor."
